# P0 — Nghiệm thu trên Android emulator (2026-10-26)

Môi trường: AVD `Pixel_6` (Android 17, API 37, 1080×2400), **Expo Go 58.0.5**, Metro `pnpm android` (bản dev). BE: server dev chung của nhóm (`api.<domain>`,
`deploy/README.md` của repo BE). Một tài khoản test vai trò **CUSTOMER** — người dùng tự nhập mật khẩu trên emulator (server từ xa, không phải localhost).
Điều khiển và lấy bằng chứng qua `adb` (ảnh chụp, `uiautomator dump`, `dumpsys`). Đối chiếu checklist ở `2026-10-25-p0-foundation-handoff.md` §1.
